Sobre o SENAI Connect

O SENAI Connect é uma plataforma de comunicação interna desenvolvida para facilitar a interação entre alunos, professores, coordenação e direção do SENAI.

Centralizamos avisos, eventos e informações importantes em um único ambiente digital, tornando a comunicação mais rápida, organizada e eficiente.

✨ Funcionalidades

🔐 Sistema de Autenticação

Login seguro com JWT, controle de sessão e permissões por roles (ADMIN, COORDINATOR, TEACHER, STUDENT)

📢 Plataforma de Posts

Criação de posts por professores e coordenação, categorias (EVENT, INTERNSHIP, PRESENTATION, ANNOUNCEMENT), visibilidade controlada

👍 Sistema de Reações

Reaja com múltiplos emojis (👍❤️😮🎉😂👎), só uma vez cada, toggle para remover, botões azuis quando ativos, persistência via API

📤 Compartilhamento

Compartilhe posts usando Web Share API ou copiando a URL, integração nativa com redes sociais

📅 Calendário Interativo

Visualização de eventos em formato de calendário, indicação de dias com atividades, navegação por meses

🔗 Mural de Links

Organização de links úteis, criação e edição por coordenação, interface em tabela com ações administrativas

🌙 Tema Escuro

Interface moderna com tema escuro otimizado, logo adaptado com fundo transparente, transições suaves

🌐 Interface Responsiva

Design responsivo compatível com celulares, tablets e computadores, adaptação automática de layout
